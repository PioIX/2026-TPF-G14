# 2026-TPF-G14
### PioZone
### Descripción General:
Nuestra aplicación es un gestor de torneos para distintos deportes (fútbol, voley y basquet), el usuario puede añadir jugadores y equipos al torneo, ademas cada usuario tiene la posibilidad de crear un chat para interactuar con otro y crear grupos. El Administrador puede crear los torneos y organizar los fixtures y fechas a jugarse entre los equipos. Ademas habra una tabla de posiciones que se actualiza cuando los administradores insertan los resultados de las fechas. El uso del socket se verá implementado en el seguimiento en tiempo real de los partidos que se esten disputando en el momento a traves del uso del socj, alli el usuario administrador ira actualizando los hechos que vayan ocurriendo.
### Problema que aborda:
Es una forma práctica de solucionar el problema de distintas organizaciones que quieren organizar un torneo, facilita el seguimiento del fixture, la gestión y organización de los torneos de una forma mucho mas ordenada que la tradicional, además permite el seguimiento en tiempo real de los partidos y cuenta con la tabla de posiciones que se va actualizando fecha a fecha.
