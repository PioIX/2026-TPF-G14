# 2026-TPF-G14
### PioZone
### Descripción General:
Nuestra aplicación es un gestor de torneos para distintos deportes (fútbol, voley, handball y basquet), el usuario puede añadir jugadores y equipos al torneo, ademas cada usuario tiene la posibilidad de crear un chat para interactuar con otro y crear grupos. El Administrador puede crear los torneos y organizar los fixtures y fechas a jugarse entre los equipos. Ademas habra una tabla de posiciones que se actualiza cuando los administradores insertan los resultados de las fechas.
